## Исправления

- Старый чек-ин больше не переносится на повторную запись или новую дату события.
- Ссылки восстановления привязаны к текущему email; изменение пароля отзывает другие сессии и незавершённые ссылки.
- Google не связывается автоматически с неподтверждённым существующим аккаунтом.
- Публичная страница организатора исключает черновики, приватные события и связанные отзывы.
- Владелец обращения получает доступ к приложенным сотрудником файлам.
- Поля кода приглашения и текущего пароля получили явные подписи.
- Сервер готовности возвращает HTTP 503 при недоступной базе. Изменение проверки в GitHub Actions подготовлено отдельно: текущий GitHub-токен не разрешает изменять workflow.
- Исправлены уязвимые версии Nodemailer, brace-expansion, js-yaml и nanoid; остальные версии в lock не обновлялись.
